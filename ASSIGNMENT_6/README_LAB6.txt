CS527 Lab 6

Implemented tasks
----------------
1. Source-level execution-frequency instrumentation.
   - compiler.c generates program.map while generating program.byte.
   - Each generated byte-code instruction is mapped to its source statement.
   - processor.c counts execution of each byte-code instruction.
   - os.c creates <program_name>_<PID>.freq when a task finishes.
   - Empty/comment-only lines and labels are excluded.
   - Expanded statements are reported once at source level.

2. Memory-resident page tables.
   - Removed the simulator-side pageTable array.
   - Added PTBR[NP] to processor state.
   - Frame 0 stores one NUM_LOGICAL_PAGES-byte page-table region per processor.
   - Page-table entries are physical frame numbers; 0 means unmapped.
   - Address translation reads the entry from physical memory using PTBR.
   - Loader/finalizer write/read page-table entries in frame 0 and reset PTBR.

Validation
----------
- `make clean && make` succeeds with the starter Makefile.
- Lab 6 sample-style loop produced the expected frequencies:
    x1 = 0                 -> 1
    x2 = 0                 -> 1
    x3 = 0                 -> 1
    x4 = [x3]              -> 1
    x15 = x1 - x4          -> 10
    BEQ .exit              -> 10
    loop body              -> 9 each
    [x3] = x2              -> 1
- Constant-address memory load expansion was tested and reported once.
- Six concurrent tasks were tested; waiting tasks were dispatched after processors became free, and all six frequency files were generated.
